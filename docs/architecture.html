ViT-S 구현 방법

student.py가 CPDINO 생성 시 백본 생성 함수를 dinov3_vits16으로 임시 교체합니다. CPDINO는 실제 백본의 특징 폭 384를 읽고 헤드를 생성합니다.

공식 Hugging Face 가중치의 이름과 Q/K/V 배열을 로컬 DINOv3 형식으로 변환한 뒤, 백본 전체를 strict=True로 불러옵니다. 체크포인트에 초기화 출처와 SHA-256을 기록합니다.

학습되는 부분과 고정되는 부분

확인한 CPDINO forward는 패치 투영의 weight와 bias에 .data를 사용합니다. 이 연산에서 패치 투영으로 gradient가 전달되지 않으며, ViT-S 280 epoch 체크포인트에서도 해당 가중치가 Meta 초기값과 정확히 같았습니다. Transformer 블록과 출력 헤드는 학습 대상입니다.

W2는 고정된 identity 기반 재배열 가중치입니다. 각 토큰의 192개 값을 8 × 8 × 3 픽셀 값으로 펼칩니다. 최종 Cellpose 마스크 생성은 flow와 세포 점수에 대한 후처리입니다.
