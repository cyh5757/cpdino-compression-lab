# 포트폴리오 — CPDINO Compression Lab

## 프로젝트 소개

**지식 증류와 소형 Vision Transformer 백본 이식을 활용한 세포 인스턴스 분할 모델 경량화**

세포 분석 시스템의 정확도와 추론 비용을 함께 살펴보기 위해 CPDINO 기반 세 가지 크기의 모델을 비교했다. ViT-L 모델을 교사로 삼아 ViT-B의 출력 증류를 수행했고, 공식 DINOv3 ViT-S 백본을 Cellpose 구조에 접목해 지도학습했다. 모델 크기, 초기화, 학습 손실, 평가 조건을 추적할 수 있도록 실험을 모듈화했다.

## 해결하려던 문제

ViT-L 기반 모델의 분할 품질을 기준으로 더 작은 모델이 어떤 정확도·지연시간 절충을 보이는지 확인하는 것이 목적이었다. ViT-B의 미세조정과 지식 증류를 비교하고, 약 21.6M 파라미터의 ViT-S 백본까지 확장했다. 사용자 데이터에 대한 초기 실험과 모듈 재구성 작업을 구분해 기록했다.

## 구현한 내용

1. **출력 수준 지식 증류** — 교사의 두 flow 채널과 foreground logit을 학생이 따라가도록 MSE를 구성했다. 원래 라벨 지도 손실을 유지하며 교사 gradient를 차단했다.
2. **ViT-S 백본 이식** — DINOv3 ViT-S의 사전학습 가중치를 확인하고 CPDINO의 공간 토큰 처리, 선형 헤드, 고정 픽셀 복원 경로에 연결했다.
3. **재현 가능한 초기화** — 가중치 SHA-256, 텐서 키·형태 검사, 학습 recipe, split 중복 검사와 체크포인트 식별자를 도입했다.
4. **실행 단위 검증** — 데이터 배치, 모델 forward, 손실, optimizer step, 검증, checkpoint 재개를 독립 Python 함수와 노트북 셀로 구성했다.
5. **비교 시각화** — 세 백본의 깊이·폭·attention head와 공통 마스크 출력 경로를 인터랙티브 다이어그램으로 정리했다.

## 관측한 성과

독립 test split 64장의 기존 측정에서 ViT-L의 AP@0.5는 0.8246, 직접 학습 B는 0.8201, 증류 B는 0.8212였다. 이미지 지연시간 평균은 각각 1265.5 ms, 843.7 ms, 806.4 ms였다. 증류 B의 AP@0.75는 직접 학습 B의 0.7322에서 0.7396으로 관측되었다.

이 값은 해당 데이터와 측정 환경의 관측 결과이다. 일부 평가 라벨은 AI 기반 생성 이력이 있으며, 반복 실험 분산과 GPU 동시 작업 통제는 기록되지 않았다. ViT-S의 최종 평가가 완료되면 동일 조건 결과를 추가한다. 정확도 향상률과 속도 개선을 일반적인 보장으로 표현하지 않는다.

## 기술적 판단

ViT-S는 ViT-B와 같은 12블록을 사용하며 특징 폭과 attention head 수가 절반이다. 출력 해상도와 Cellpose 마스크 생성 방식은 같은 원리를 따른다. 모델 경량화의 영향을 해석할 때, S의 헤드가 새로 초기화된다는 점과 B의 기존 분할 사전학습을 함께 고려했다.

원본 구현의 전역 생성 함수 교체를 명시적인 encoder 주입으로 재구성해 동작 경계를 좁혔다. 또한 upstream forward에서 gradient가 차단되는 패치 투영을 조사하고, 고정되는 동작을 코드와 테스트에 표시했다.

## 기여와 기반 기술

기반 모델과 핵심 알고리즘의 출처는 Meta DINOv3와 MouseLand Cellpose이다. 이 프로젝트는 사용자가 설계한 비교 실험, 백본 연결, 증류 학습, 결과 분석과 재현 구성에 대한 포트폴리오이다. 코드 정리와 문서 작성에는 AI 코딩 도구를 활용했다.

> CPDINO 세포 분할 모델의 추론 비용을 줄이기 위해 ViT-L에서 ViT-B로 출력 증류를 적용하고, 더 작은 DINOv3 ViT-S 백본을 CPDINO에 이식해 지도학습했습니다. 모델의 깊이와 폭, 초기 가중치와 손실 함수를 분리해 검증했으며, 정확도와 지연시간 비교를 재현 가능한 Python 모듈과 노트북으로 구성했습니다.
